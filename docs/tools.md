## Resources

- `devkit://status`: Live editor status, engine version, active level, and dirty package status.
- `devkit://logs/recent`: Ring buffer of the latest Output Log entries recorded by ConanMCP.
- `devkit://outliner`: Structured hierarchical list of all actors in the currently loaded level.
- `conan://tables`: Catalog of all Conan Exiles item, recipe, spawn, and gameplay DataTables.
- `conan://asset/{package_path}`: Inspect metadata, class, dependencies, and referencers of any asset by package path.
